# Generated documents

Everything in this folder except this README is **generated from the sources in
`Assets/`**. It exists so the project can be handed to a tool that reads
documents rather than a repository — a Claude Project, for instance.

`Assets/` is the only source of truth. These files go stale the moment code
changes, so regenerate them before relying on them.

| File | Covers |
|---|---|
| `CODE-1-gameplay.md` | puzzle, segments, operator, clock |
| `CODE-2-online.md` | Firebase, lobby, 1v1 matches, bot |
| `CODE-3-progression.md` | ELO, leaderboards, daily, coins, ads |
| `CODE-4-ui-runtime.md` | panels, audio, layout, tutorial |
| `CODE-5-scenebuilder.md` | the UI generator |
| `CODE-6-firebase-rules.md` | database rules, annotated |

The project overview lives at `MATHSTICK.md` in the repository root, and is
written by hand — that one is not generated.
